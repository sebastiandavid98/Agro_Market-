# AgroMarket DD 🌿

Plataforma digital que conecta directamente a agricultores, consumidores y negocios, facilitando la publicación, búsqueda y compra de productos agrícolas.

## Integrantes
- **Sebastian Dario David Marcillo**
- **David Alejandro Salas Ibarra**

## Descripción
AgroMarket busca fortalecer la comercialización del campo, reducir intermediarios y brindar a los productores mejores oportunidades para ofrecer sus productos de forma rápida, sencilla y accesible.
